## Original Execution Brief

The template will use an editorial black-ink and bone-paper palette with a serif display face, restrained sans-serif metadata, and a left-aligned, magazine-like hierarchy. The gallery will use CSS multi-columns as a responsive Pinterest-style masonry treatment: source order remains accessible, tiles pack vertically without row gaps, and desktop establishes three columns before reducing to two and then one column. Each image receives a minimal glassmorphism caption surface and a dark gradient contrast layer. Motion will be limited to opacity/transform reveals controlled by Intersection Observer, with smooth anchor scrolling and a `prefers-reduced-motion` fallback.
